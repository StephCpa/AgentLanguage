# 动态记录教学补充

本目录是下一轮材料的可编译补充，不修改 DeepSeek pilot v1 的冻结提示。

两组例子共用 `ExampleRecord {value: Text}` Catalog。输入是运行时 Text 参数，构造记录后再读出该字段，不涉及 Git 发布、故障分支或任务参考答案。

AL-0 的 `{value: "fixed"}` 是数据字面量，不能把运行时变量放进这个字面量。动态记录使用 `record("ExampleRecord", {value: value})`，其中右侧 value 是已声明的引用。SDK 使用共同 PlanBuilder.record 构造记录，字段和 schema 在共享 IR 中检查；生成绑定提供参数、字段读取和记录的 Python 类型。两个文件都由真实前端构造，并检查规范 IR 相同。

共同输出协议接受原始源码或恰好一个完整代码围栏；不从混合说明或多个代码块中猜测源码。解析器保存原始文本、提取后文本、版本和两者摘要。这套协议仅供未来显式选择它的实验使用，历史原样评分和事后围栏敏感性分析保持原有口径。
